# Visual Style Profile

The visual language for all Pipeline Lab video and brand assets.

- **Art Style:** Cinematic real-footage talking head blended with two graphic modes: minimalist flat-vector motion graphics on clean backgrounds, and dark-mode screen recordings with a floating rounded-corner facecam. Playful pixel-art mascots and game-style UI (levels, XP bars) for storytelling.
- **Color Palette:** Footage — near-black backgrounds, deep navy/teal window bokeh, warm skin tones, white/black wardrobe, very high contrast. Graphics — bright off-white or pure black canvases with an emerald-green → royal-blue gradient accent system, orange/rust as secondary pop.
- **Lighting:** Dramatic low-key studio lighting; soft key light on subject, vertical white LED tube lights in the background, blue city-light bokeh. Moody, premium, "night studio" atmosphere.
- **Camera Composition:** Centered medium close-up, broadcast mic in lower third, shallow depth of field. Screen-share mode: facecam shrinks to a rounded vertical card pinned left, demo fills the frame.
- **Subject Design:** Single presenter, minimal casual wardrobe, mic as a visual brand element. Simple geometric/pixel characters with labels in graphics.
- **Aesthetic Signature:** "Dark cinematic night studio meets clean minimalist infographics." High contrast is the unifying thread.
- **Faceless Adaptation:** Replace the talking-head layer with the dark cinematic mood, tube-light aesthetic, gradient stat graphics, and dark-mode screen recordings as the core visual language.
